# 🔐 SecureChat — Military-Grade Encrypted Messaging Platform

SecureChat is an advanced end-to-end encrypted messaging web application built as an Information Security semester project. The project focuses on robust cryptographic protocols, real-time communication, and automated threat mitigation.

---

## 🤖 AI-Assisted Development (Vibe Coding)
This project was built using an **AI-assisted development workflow (Vibe Coding)** powered by **Claude**. 
* **My Role:** System Architect & Director. I designed the security blueprint, defined the core logic, chose the cryptographic protocols, and guided the entire development process.
* **AI's Role:** Coding Partner. Claude assisted in writing, optimizing, and accelerating the codebase based on precise structural prompts.

---

## 🔐 Core Security Features

- **End-to-End Encryption (E2EE):** Hybrid cryptography combining **AES-256** for message encryption and **RSA-2048** for secure key exchange.
- **Real-Time Messaging:** Secure bi-directional communication powered by **Socket.IO**.
- **Multi-Factor Authentication:** Robust User Authentication coupled with **Two-Factor Authentication (2FA)**.
- **Brute-Force Protection:** Rate-limiting mechanisms with automatic account lockout policies.
- **AI-Powered Threat Detection:** Real-time inspection and blocking of web attacks like **SQL Injection (SQLi)** and **Cross-Site Scripting (XSS)**.
- **Live Firewall Simulation:** Visual interface showing incoming connection logs and traffic monitoring.
- **Security Auditing:** Tamper-evident system logs mapping out all authentication and system actions.
- **Zero-Knowledge Architecture:** Session timeouts and design principles ensuring servers never store unencrypted user data.
- **UI/UX:** Over 10+ professional, responsive security-focused web pages.

## 💻 Tech Stack

* **Backend:** Python (Flask), Flask-SocketIO
* **Database & Storage:** SQLite, SQLalchemy
* **Security & Cryptography:** PyCryptodome (AES, RSA, SHA-256), bcrypt
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
